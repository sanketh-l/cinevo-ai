## 1. Project Overview

FlowGen AI is a free, cloud-based AI video generation platform replicating Google Flow's core features, backed entirely by free GPU compute platforms (Kaggle, HF ZeroGPU, Colab) and free APIs (Pollinations, edge-tts).

**Target User**: Faceless YouTube content creators  
**Output**: 8-10 sec 1080p horizontal video clips, stitchable into longer videos  
**Cost**: $0/month (amortized across free accounts)

---

## 2. Google Flow Features to Clone

| Feature | Google Flow | FlowGen AI Equivalent |
|---|---|---|
| Text-to-Video | Describe scene → generate clip | Same (Kaggle/HF/Colab GPU) |
| Image-to-Video | Upload photo → animate | Same + Pollinations enhancement |
| Ingredients System | Upload/generate characters, lock consistency | Same + Canny edge extraction |
| Camera Controls | Pan, tilt, zoom, dolly | Wan 2.1 camera motion params |
| Scenebuilder | Drag clips into timeline, arrange | Custom timeline UI + FFmpeg |
| Sceneextend | Fill gaps in generated video | Custom inpaint + extend logic |
| Asset Library | Browse, search, manage ingredients | Supabase DB + Google Drive storage |
| Voiceover | Built-in narration | edge-tts (100% free, all languages) |
| Film Grain/Style | Apply film grain, vintage look | FFmpeg filters |
| Filmmaker Mode | Vertical / Horizontal / Square | Aspect ratio selector in UI |
| Project Management | Save, resume, export projects | Supabase DB + Drive storage |
| Export | 1080p final video | FFmpeg stitch + Google Drive download |

### Data Flow
```
1. User uploads reference images + enters prompt
        ↓
2. Frontend sends to FastAPI backend
        ↓
3. Backend checks queue, routes to best available GPU
        ↓
4. GitHub Actions workflow triggered
        ↓
5. GPU platform downloads model + runs inference
        ↓
6. Generated video uploaded to Google Drive
        ↓
7. Backend updates Supabase DB with video URL
        ↓
8. Frontend polls status, shows preview when ready
        ↓
9. User arranges clips in timeline (Scenebuilder)
        ↓
10. FFmpeg stitches final video
        ↓
11. Final video uploaded to Drive, download link sent
```

## 5. User Workflow (Matching Google Flow)

### 5.1 Account Setup
1. Sign up with email/password (Supabase Auth)
2. Connect Google account (OAuth → Drive access)
3. Dashboard shows: Projects, Ingredients, Generate

### 5.2 Create Project
1. Click "New Project"
2. Name it, choose aspect ratio (16:9 horizontal for YouTube)
3. Enter project workspace

### 5.3 Generate Ingredients (Characters/Assets)
1. Click "Ingredients" tab
2. **Option A**: Describe → Pollinations generates character image
3. **Option B**: Upload your own reference photo
4. Click "Lock" to save as ingredient (character stays consistent)
5. **Option C**: Use pre-made styles (anime, realistic, cinematic, etc.)

### 5.4 Generate Video Clip
1. Click "Generate" tab
2. **Ingredients section**: Select locked characters/assets
3. **Prompt section**: Describe the scene in natural language
4. **Camera controls**: Choose pan/tilt/zoom if needed
5. **Settings**: Aspect ratio, duration (5-10 sec), style
6. Click "Generate Video"
7. Queue position displayed, progress bar shown
8. Preview video when ready (low-res first, full-res download)

### 5.5 Arrange in Scenebuilder (Timeline)
1. Click "Timeline" tab
2. Drag video clips from sidebar into timeline
3. Rearrange clip order
4. Trim clip endpoints
5. Add transitions between clips
6. Add voiceover to each clip (edge-tts)
7. Add film grain / style filters
8. Preview full sequence

### 5.6 Export
1. Click "Export"
2. Choose: 1080p, 4K (if model supports)
3. FFmpeg stitches all clips + voiceover + filters
4. Final video saved to Google Drive
5. Download link provided
6. Option to publish directly to YouTube (future)

## 8. GPU Platform Integration

### 8.1 Kaggle Integration
- **API**: Kaggle REST API
- **Auth**: Username + API key per account
- **10 accounts** for rotation
- **Workflow**:
  1. Backend selects least-used Kaggle account
  2. Triggers notebook via Kaggle API
  3. Notebook loads Wan 2.1 14B (FP8) from HF
  4. Runs inference with prompt + optional image
  5. Uploads video to Google Drive
  6. Returns result URL to backend

### 8.2 HF ZeroGPU Integration
- **API**: HuggingFace Spaces API
- **Auth**: HF token per account
- **5 accounts** for rotation
- **Workflow**:
  1. Backend selects least-used HF account
  2. Calls HF Space API with prompt + image
  3. Space runs ZeroGPU inference
  4. Returns video URL

### 8.3 Google Colab Integration (Manual)
- **For large projects only**
- **Workflow**:
  1. User clicks "Run on Colab" button
  2. Opens pre-built Colab notebook in browser
  3. User clicks "Run All"
  4. Notebook generates all queued videos
  5. Downloads final videos to user's machine

### 8.4 GitHub Actions Queue
- **Public repo**: unlimited free minutes
- **Dispatch workflow** with payload (prompt, image URL, settings)
- **Matrix strategy**: rotate through accounts
- **Timeout**: 30 min per job
- **Retry**: up to 2 retries on failure

| 10 Kaggle accounts | ~30 hrs total | ~36-60 clips |
| 5 HF accounts | ~25 min total | ~5-10 clips |

| **Total** | **~42+ hrs** | **~55-98 clips** |

### Account Rotation Logic
```python
def select_best_platform(job_priority='normal'):
    accounts = get_available_accounts()
    
    # Sort by: priority queue position, account quota remaining, GPU VRAM
    for account in sorted(accounts, key=lambda a: (
        a.quota_remaining,
        a.vram,
        a.queue_length
    )):
        if account.quota_remaining > job_estimated_time:
            return account
    
    # All accounts busy → queue job, notify user
    return None
```
